# Zotero 论文重点总结

在 Zotero 的 PDF 阅读器右上角点击带金色星标的蓝色文档图标，展开 **论文总结**。再次点击可收起。右侧面板按研究问题、创新点、研究方法、主要结果和局限性整理中文要点。每条要点都关联到一处或多处可定位的原文，只显示模型找到依据的类别。

## 安装

在 Zotero 10 的 **工具 → 插件 → 齿轮 → 从文件安装插件** 中选择 [zotero-paper-insights-0.5.1.xpi](https://github.com/MrBear9/zotero-paper-insights/releases/download/release/zotero-paper-insights-0.5.1.xpi)。用内置阅读器打开一个 PDF。安装时已经打开的 PDF 标签页可以关闭后重新打开。

## 在阅读器中使用

1. 点击阅读器工具栏的 **论文总结** 图标，展开 **模型与标注设置**。默认使用 Codex CLI 和高亮，也可以选择 API 和下划线。
2. 点击 **生成总结并标注**，可勾选 **详细讲解研究方法**，也可填写本次要求，例如“重点讲解训练流程、对照实验和评价指标”。点击 **开始生成** 后，插件按页提取带坐标的正文，分段交给模型，长文再整合各段要点。开始生成时会保存当前模型配置。本次要求适用于 Codex 和模型 API，会用于每段提取和全文整合。已有总结的 PDF 可点击 **按新要求补充总结**。新要点会追加到现有结果；同一处原文复用已有的总结批注。
3. 点击任意一句总结，阅读器会跳到对应原句，并短暂突出显示该位置。展开 **原文依据** 可以看到每处证据的页码和原句，分别点击即可定位，包括跨页证据。
4. 在可编辑文库中，插件把结果写为 Zotero 原生批注，标签为 **论文重点总结**。一处原文支持多个要点时共用一个批注。重新打开 PDF 即可从批注恢复总结，也可用 Zotero 自身的批注功能查看或导出。插件仅在生成完成时写入，不修改源 PDF 文件。只读附件支持在当前阅读窗口查看总结和定位。

拖动 PDF 和总结面板之间的分隔线即可左右调宽或调窄，松开后记住宽度。窄窗口会改用底部面板。在要点文字或其原文依据上点右键，或左键点要点旁的 **⋯**，即可打开复制和删除菜单。确认删除后，该要点专用的高亮和下划线会同步从 PDF 阅读器中消失。共用同一处原文的其他要点仍可点击、定位。

点击 **清除本篇总结…** 并确认，可同时清空当前 PDF 的总结和对应原文标注。移除的总结批注连同附加评论和标签进入 Zotero 回收站。单独创建的手工批注和其他文献的总结会保留。

## 模型配置

### 暂停与继续

生成过程中可以点 **暂停**。网络中断或模型请求失败后，点 **继续生成** 即可沿用原模型、标注样式和本次要求。关闭 PDF 或重启 Zotero 后，也可以打开同一附件继续。使用需要密钥的 API 时，重启后请在原接口下重新填写 API Key。

插件在每段提取和每批全文整合完成后保存进度。恢复时会重新读取本地 PDF 核对原文，跳过已保存的模型调用，从尚未完成的一段或一批开始。短文如果只有一段且首次请求中断，该段需要重新请求。批注在全文总结完成后统一写入。进度文件位于 Zotero 数据目录下的 `paper-insights-progress`，完成任务或点击 **放弃本次进度** 后删除。放弃进度可重新选择模型和总结要求。

### 选择模型

- **Codex CLI** 使用本机已登录的 Codex。展开 **模型与标注设置** 后，列表自动显示所选 CLI 自带的模型。旧版 CLI 使用本机缓存。点击模型即可选中。也可输入模型 ID。留空使用 CLI 默认模型。可执行文件通常留空；自定义安装可指定二进制文件完整路径。需要支持 `codex exec --ephemeral --ignore-user-config` 的版本。
- **模型 API** 支持 OpenAI 兼容的 Chat Completions 接口。填写服务商给出的地址（如 `https://api.openai.com/v1` 或含 `/chat/completions` 的完整地址）和 API Key，完成输入后会通过服务的 `GET /models` 获取模型列表，点击即可选择。可点击 **刷新模型列表** 重新读取；未提供列表的服务可手动填写模型 ID。本地服务支持 `http://127.0.0.1:端口/v1`。API Key 按接口保存在本次 Zotero 会话的内存中，重启后需重新填写。模型名称、地址和标注样式保存在本地设置中。

## 原文定位

模型接收的是带编号的 PDF 原文。插件校验返回的编号，然后从本机文本层取回原句和逐行矩形坐标。高亮与下划线均按原文范围保存。同一句总结可以汇集不同段落或页面的证据。文本层顺序取决于 PDF 本身，多栏排版、公式和已有 OCR 的错误会影响阅读结果。纯扫描 PDF 请先进行 OCR。模型生成的中文表述可用下方原文逐句核对。

## 构建

在本目录运行 `python scripts/build.py`，生成的 XPI 位于 `dist/`。构建使用 Python 标准库。插件源码位于 `addon/`，使用 GNU AGPL v3 许可。
